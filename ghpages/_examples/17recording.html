Integrated multi-track recording using AudioWorklet for professional Audacity-style recording workflow.

Features:
  • Integrated Recording: Record directly into selected tracks (Audacity-style)
  • Automatic Clip Creation: New clips automatically added when recording stops
  • Recording Positions: Start at time 0 or append after existing clips
  • Track Management: Add tracks on-the-fly and select which track to record into
  • AudioWorklet-based: Low latency, real-time waveform visualization
  • VU Meter: Monitor input levels with peak hold
  • Microphone Selection: Choose from available input devices
Note: This example requires HTTPS or localhost. Make sure to grant microphone permissions when prompted.
