🚀 Performance Optimization with waveform-data.js

This example demonstrates loading pre-computed waveform data using the waveform-data.js format, developed by BBC R&D.

Benefits:
  • ⚡ 10-50x faster loading - Waveforms appear instantly without computing peaks from audio
  • 💾 Reduced bandwidth - .dat files are smaller than computing peaks in-browser
  • 🔄 Industry standard - Compatible with tools like Audiowaveform, Peaks.js, and other BBC tools
  • 📦 Pre-generation - Generate .dat files server-side for instant client-side display
How it works:
  1. Generate .dat files using audiowaveform CLI tool
  2. Load .dat files with loadPeaksFromWaveformData()
  3. Display waveforms instantly while audio files load in parallel

💡 Check the browser console to see the performance comparison between loading waveform data (.dat files) vs. decoding audio files (.mp3).

📚 Code Example

import { loadPeaksFromWaveformData } from '@waveform-playlist/browser';

const audioFiles = [
  { id: 'vocals', audioSrc: 'media/vocals.mp3', datSrc: 'media/vocals.dat' },
  { id: 'guitar', audioSrc: 'media/guitar.mp3', datSrc: 'media/guitar.dat' },
];

// Step 1: Load ALL waveform data files in parallel (instant!)
const peaksPromises = audioFiles.map(file =>
  loadPeaksFromWaveformData(file.datSrc)
);
const peaksResults = await Promise.all(peaksPromises);

// Step 2: Load ALL audio files in parallel (slower, for playback)
const audioPromises = audioFiles.map(async (file) => {
  const response = await fetch(file.audioSrc);
  const arrayBuffer = await response.arrayBuffer();
  return await audioContext.decodeAudioData(arrayBuffer);
});
const audioBuffers = await Promise.all(audioPromises);

// Waveforms display instantly while audio still loads! ⚡

🛠️ Generating .dat Files

Use the audiowaveform CLI tool to generate waveform data files:

# Install (macOS)
brew install audiowaveform

# Generate .dat file (binary format - fast & small)
audiowaveform -i vocals.mp3 -o vocals.dat -z 256

# Or generate .json file (human-readable, larger)
audiowaveform -i vocals.mp3 -o vocals.json -z 256

-z parameter sets zoom level (samples per pixel). Common values: 128 (high detail), 256 (balanced), 512 (overview).
