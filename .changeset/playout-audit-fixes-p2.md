Correctness audit fixes (part 2): `getMediaStreamSource` now creates sources on the global playout context (not Tone's orphaned default) and its automatic cleanup actually fires (track-level `ended` listeners — `MediaStream` has no `ended`/`inactive` events, so the old listeners never ran and every entry leaked); `configureGlobalContext` honors `latencyHint` in the default (standardized-audio-context) path; `MidiToneTrack.stopAllSources` guards each synth's `releaseAll` individually so a melodic failure can't leave percussion voices stuck; `duration` getters on all three track classes return the max clip end instead of the array-last clip's end; clips added or swapped in during playback now get their fade envelopes scheduled (previously flat gain until the next play); `getUnderlyingAudioParam` returns undefined for null/undefined input; `SoundFontCache.load` fetch errors include the HTTP status code; missing-SoundFont-sample warnings rate-limit per track instance instead of once per page; `fades.ts` no longer re-exports core's fade utilities (import them from `@waveform-playlist/core`; unreachable externally, no public API change); all `console.warn` calls pass a single concatenated string (Chrome lazily evaluates logged objects); `connectMasterOutput`/`connectEffects` guard their disconnect step so an externally-disposed chain node can't abort the rewire.
